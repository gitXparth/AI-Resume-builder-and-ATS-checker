# Resume Builder

A React app with a resume editor, live preview, and a simple ATS keyword-match checker.

## Setup

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Project structure

```
resume-builder-app/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx          # React entry point
    └── ResumeBuilder.jsx # Main app component
```
